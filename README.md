# Cyan Cut — Windows downloads

Official binary releases for Cyan Cut.

- [Download the latest release](https://github.com/cyan881990/cyan-cut-releases/releases/latest)
- **Setup**: Windows installer with automatic updates.
- **Portable**: standalone build; update manually.
- A CyanPro account/license is required for editing and export: https://cyanpro.app

This repository hosts installers and update metadata only. Application source and its Git history are maintained separately and are not published here.
